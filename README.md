### ▶️ Running a lab

Most exercises are **standalone Python scripts** that read input from standard input. For example:

```bash
python3 lab06.py
```

Enter the values expected by that particular exercise. No third-party packages are required for the main labs.

> These are archived university exercises from an introductory course, not production applications. The original code and its learning progression have been preserved; no claim of automated test coverage is made.
